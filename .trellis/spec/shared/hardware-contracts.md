# 项目运行时边界

本仓库是文档、模板和开发工具仓库，不连接 MCU、传感器或其他硬件，也不维护
Flash、DMA、ISR、寄存器或板级协议合同。

- 受保护资源：安装脚本的目标路径校验、冲突检测、备份清单和回滚行为。
- 持久化边界：`.git/trellisforge-backup/` 仅保存被覆盖文件及 SHA-256 清单；
  不把备份写入工作树，也不复制目标仓库运行状态。
- 并发边界：脚本按单次安装执行；不并行写入同一目标文件，异常时恢复本次已覆盖文件。
- 发布兼容性：模板中的项目目录前缀、项目正文前缀和项目名称字段必须完整替换；
  下游嵌入式 C 合同由目标仓库接入时填写，不能在本仓库宣称已验证。
- 硬件验证：`not applicable`。任何下游硬件验证必须由下游项目用户确认。
